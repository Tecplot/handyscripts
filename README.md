# Useful Scripts for Tecplot Products

These scripts use PyTecplot, PyFieldview, Tecplot 360's macro language, and FVX. 

This repo includes examples that come with product installs, common workflows that you might find in our webinars and KB articles, as well as some bespoke solutions that have helped customers in the past.
